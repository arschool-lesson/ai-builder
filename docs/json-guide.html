前回のおさらい：CSVファイル

タイピングゲームでは、問題データを
CSV（シーエスブイ）という形式で管理しました。

words.csv
apple,りんご
banana,バナナ
cat,ねこ
dog,いぬ

CSVはカンマ（ , ）で区切っただけのシンプルな形式。
「英単語」と「日本語の意味」のような
2つの情報をセットにするのに向いています。

CSVだと困ることがある

国旗クイズには、1つの問題にたくさんの情報が必要です。

国名、画像、地域、難易度、選択肢1、選択肢2、選択肢3、選択肢4、正解番号

これをCSVで書くと……

jp,日本,flags/jp.png,アジア,1,日本,韓国,中国,モンゴル,0
fr,フランス,flags/fr.png,ヨーロッパ,1,フランス,ドイツ,イタリア,スペイン,0

どのカンマが何番目かわからなくなる。
「5番目のカンマの後が選択肢1で……」なんて数えるのは大変。
読みにくいし、間違いやすい！

JSONなら「名前付き」で書ける

JSON（ジェイソン）は、データに名前をつけて書ける形式です。

quiz.json（1問分）
{
"country": "日本",
"image": "flags/jp.png",
"region": "アジア",
"difficulty": 1,
"choices": ["日本", "韓国", "中国", "モンゴル"],
"correctIndex": 0
}

"country" が国名、"region" が地域、"choices" が選択肢……
名前がついているから、何がどのデータかすぐわかる！

CSVはスプレッドシート（Excel）向き。JSONはWebアプリ向き。
どちらが良い悪いではなく、用途によって使い分けます。

JSONの書き方ルール

{ } で囲む

1つのデータのまとまりは
波カッコ { } で囲みます。
これを「オブジェクト」と呼びます。

"名前": 値

データは"名前": 値 の形で書きます。
名前は必ずダブルクォーテーション " " で囲みます。

[ ] はリスト

複数の値を並べるときは
角カッコ [ ] で囲みます。
選択肢のように同じ種類のものが複数あるときに使います。

, で区切る

データが複数あるときは
カンマ , で区切ります。
ただし最後の項目の後にはカンマを付けないのがルール。

値にはいろいろな種類がある

{
"country": "日本", ← 文字列（" " で囲む）
"difficulty": 1, ← 数値（そのまま）
"choices": ["日本", "韓国"], ← リスト
"correctIndex": 0 ← 数値
}

correctIndex の「0」って？

プログラムの世界では、番号を0から数えます。

choices: ["日本", "韓国", "中国", "モンゴル"]
     0番目 1番目 2番目 3番目

correctIndex: 0 → 正解は0番目の「日本」

複数の問題を並べる

1問ずつの { } を、[ ] の中にカンマ区切りで並べるとクイズデータの完成！

quiz.json
[
{
"country": "日本",
"image": "flags/jp.png",
"region": "アジア",
"difficulty": 1,
"choices": ["日本", "韓国", "中国", "モンゴル"],
"correctIndex": 0
}, ← カンマで区切る
{
"country": "フランス",
...
}
]

全体を [ ] で囲むのを忘れずに。
最後の問題の } の後にはカンマを付けません。

国旗クイズのデータ構造

1問分のデータには、次の情報が入っています。

{
"code": "jp", ← 国コード（画像名と同じ）
"country": "日本", ← 国名
"image": "flags/jp.png", ← 国旗画像のパス
"region": "アジア", ← 地域（6つ）
"difficulty": 1, ← 難易度（1:簡単 2:普通 3:難しい）
"choices": [ ← 選択肢（4つ）
"日本", "韓国", "中国", "モンゴル"
],
"correctIndex": 0 ← 正解（0番目 = "日本"）
}

AIにJSONデータを作ってもらおう

構造がわかったら、AIにお願いして
クイズデータを作ってもらいましょう！

一度に全部頼むのではなく、少しずつ確認しながら進めるのがコツです。

ステップ1：まず構造を伝えて少しだけ作ってもらう

「世界の国旗クイズを作りたい。まずは2〜3問だけ、
さっき学んだJSONの形で作ってみて」

→ できたデータを見て、構造が合っているか確認する。

ステップ2：OKなら残りを全部お願いする

「いい感じ！この構造で、世界中の全ての国の分を作って。
地域ごとに分けて、有名な国とマイナーな国で
難易度も変えてね」

→ 量が多いので、地域ごとに分けて頼んでもOK。

JSONの構造を理解しているから、
AIが作ったデータが正しいかどうか自分で判断できる。

まとめ

CSVはカンマ区切りのシンプルな形式。列が少ないデータに向いている。

JSONはデータに名前をつけて書く形式。複雑なデータでも読みやすい。

JSONの構造を理解していると、AIに具体的で正確な指示を出せる。

Webアプリのデータ管理にはJSONがよく使われている。
プロのエンジニアも同じ形式を使っている。
