# テーマ1: タイピングゲーム

日本語の単語をローマ字で入力する、シンプルなタイピング練習ゲームの完成形です。

## 遊び方

1. `index.html` をブラウザで開く(または GitHub Pages 経由でアクセスする)
2. **START** ボタンを押すとゲーム開始
3. 画面に表示される日本語の単語を、キーボードでローマ字入力する
4. 制限時間 **60秒** 以内に、できるだけ多くの単語を正解する
5. 時間切れになると **RESULT** 画面が表示される。**RETRY** で再挑戦できる

## 画面の見方

- **スコア**: 正解した単語の数
- **タイマーバー** / **のこり**: 残り時間(秒)
- **日本語**: 入力するお題の単語
- **ローマ字**: 入力済みの文字が色付きで表示される

## ファイル構成

```
theme1-typing-game/
├── index.html   # 画面構造(スタート / ゲーム / リザルトの3画面)
├── style.css    # 見た目のスタイル
├── words.js     # 出題する単語データ(日本語 + ローマ字)
└── main.js      # ゲームロジック(入力判定・スコア・タイマー)
```

## 技術ポイント

- フレームワーク不使用の **素の HTML / CSS / JavaScript** のみ
- かな → ローマ字の入力判定は `main.js` 側でマッピングを持っており、
  `shi` / `si`、`tsu` / `tu` のような複数の打ち方に対応している
- ビルド不要。ブラウザでそのまま開けば動く

## ローカルで動かす

リポジトリルートから簡易サーバーを起動して開きます。

```bash
python3 -m http.server 8000 --directory docs
# → http://localhost:8000/theme1-typing-game/
```
