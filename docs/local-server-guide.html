このとき、ブラウザのアドレス欄には

これはパソコンの中のファイルを直接ひらいている状態。
インターネットにはつながっていません。

直接ひらくと困ることがある

HTMLファイルには CSS や JavaScript など
他のファイルを読み込むための指示が書いてあります。

読み込める

HTMLに最初から書いてある読み込み指示

CSSファイル、JavaScriptファイルなど、
HTMLが「このファイルも一緒に使います」と
最初から宣言しているものは読み込めます。

読み込めない

あとから追加で読みに行くファイル

たとえばクイズの問題データ（JSONファイル）のように、
JavaScriptが「実行中にこのデータをください」と
リクエストするものはブロックされます。

なぜブロックされるの？

たとえ話

もしWebページが自由にパソコンの中のファイルを読めたら、
悪意のあるサイトがパスワードや個人情報を
勝手にのぞき見できてしまいます。

だからブラウザは「安全のために、
パソコンのファイルへの自由なアクセスは禁止！」
というルールであなたのパソコンを守っています。

このセキュリティの仕組みがあるから、
file:// でひらいたページでは
JSONのようなデータファイルを読み込めないのです。

「サーバー」ってなに？

たとえ話

レストランで注文すると、ウェイターが料理を持ってきてくれますよね。

Webの世界でも同じで、ブラウザが「このページをください」とお願いすると、
サーバーがファイルを届けてくれます。

「サーバー（server）」は英語で「届ける人・給仕する人」という意味です。

ブラウザ
「このページちょうだい！」
⇄
サーバー
「はいどうぞ！」

「ローカルサーバー」は
自分のパソコンで動くサーバー

開発中は、インターネット上のサーバーではなく
自分のパソコンの中に小さなサーバーを立ててテストします。

直接ひらく

アドレス：file://...

サーバーなしで直接ひらく
→ データの読み込みができない
→ アプリが動かない

ローカルサーバー経由

アドレス：http://localhost:8080

サーバーを通してひらく
→ データの読み込みができる
→ アプリがちゃんと動く！

「localhost」は「自分のパソコン」を指す特別なアドレスです。
外からはアクセスできない、自分だけのサーバーです。

ローカルサーバーの立て方

方法 1：VS Codeの「Live Server」

VS Codeに Live Server という
拡張機能を入れておきます。

1. VS Codeで index.html を選択する
2. 右下の「Go Live」ボタンを押す

これだけでサーバーが立ち上がり、
ブラウザでアプリが自動で開きます。
ファイルを保存するたびに画面も更新されます。

方法 2：AIに頼む

GitHub CopilotやCodexなどの
AIエージェントに

「ローカルサーバーを立てて
ブラウザで開いて」

とお願いするだけでもOK！
AIが自動でサーバーを起動して
ブラウザで開いてくれます。

作ったアプリをみんなに見せたい！
