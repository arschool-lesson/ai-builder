# ai-builder

AIアプリ開発コース(バイブコーディングレッスン)で生徒に見せる教材置き場です。
レッスンで作る完成形のサンプル(HTML / JS / CSS など)をここに集約します。

## 想定する利用者

- **生徒**: 完成形を動かして、ゴールイメージを掴むために参照する
- **講師**: レッスン中に「こういうものを作ります」と提示する見本として使う

公開リポジトリとして運用するため、機密情報・APIキーなどは絶対にコミットしません。

## 公開方法

GitHub Pages を使い、`docs/` フォルダを公開ディレクトリとしてホスティングします。
リポジトリ設定の **Settings → Pages → Source** で `main` ブランチの `/docs` を指定してください。

## ディレクトリ構成

各レッスンの完成形は `docs/<lesson-name>/` に配置します。`docs/index.html` がトップページ(レッスン一覧)です。

```
ai-builder/
├── README.md
├── CLAUDE.md
└── docs/                  # ← GitHub Pages の公開ルート
    ├── index.html         # レッスン一覧トップページ
    └── <lesson-name>/     # 各レッスンの完成形
        ├── index.html
        ├── ...
        └── README.md      # そのレッスン固有の説明(任意)
```

新しいレッスンを追加したら、`docs/index.html` の一覧にもリンクを追記します。

## ローカルで動かす

静的ファイルなので、`docs/` を簡易サーバーで配信すれば動きます。

```bash
# Python が入っている場合
python3 -m http.server 8000 --directory docs

# Node が入っている場合
npx http-server docs
```

ブラウザで `http://localhost:8000/` を開きます。

## ライセンス / 取り扱い

レッスン受講者および一般に公開する前提の教材です。
生徒が自由に閲覧・改変して学べることを優先します。
